Return strictly before30 minutes: confirm old departure first, cancel exitAt, same LibraryVisit ID/original start and automatic timer ID, add [awaySince,reconnection] to awayRanges then clear awaySince, resume from reconnection and reactivate vibration. BOTH Library and Actual exclude the confirmed away gap permanently, including repeated cycles/midnight/reopen.
