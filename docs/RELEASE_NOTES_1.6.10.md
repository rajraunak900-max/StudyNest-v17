# StudyNest 1.6.10 release notes

- Daily Goal uses Actual Study alone, excluding distraction and unknown usage.
- Home Study Timer shows today's total Actual across sessions. It retains the total when a session ends or a new one starts and resets for the new local calendar day.
- Streaks use Actual Study, preserving their separate configured threshold, as explicitly requested.
- The existing App Monitoring explanation expands into view, has clear expanded/collapsed feedback, and preserves search and unsaved app selections.

The stable 1.6.9 tracking engine, 90-second departure confirmation, 30-minute session grace, sound, reminders, History, settings, database and original signing identity remain unchanged. Version 1.6.10 / code 20. Install over 1.6.9 without uninstalling or clearing data. Physical acceptance is still required.
