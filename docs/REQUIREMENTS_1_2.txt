==================================================

1. Wait approximately 20–30 seconds.

This prevents temporary Wi-Fi instability from repeatedly changing the
phone between Sound and Vibration.

OPTION 1 — AUTO-RESTORE VIBRATION AFTER 5 MINUTES
--------------------------------------------------

→ VIBRATION

I manually select SOUND
→ SOUND temporarily remains active

5 minutes pass
→ Still connected to library Wi-Fi
→ Still Sound
→ StudyNest automatically restores VIBRATION.

If I manually restore VIBRATION before 5 minutes:
→ Cancel the pending automatic restoration.

If I leave/disconnect from ALL authorised library Wi-Fi before 5 minutes:
→ Cancel the pending restoration.
→ Follow normal library-exit behaviour.
→ Ensure NORMAL SOUND MODE is enabled.

--------------------------------------------------

Library Wi-Fi connects
→ StudyNest activates VIBRATION MODE.

VIBRATION → SOUND

2. Respect my manual choice.

4. Show ONE notification only.

"StudyNest: Your phone is still in sound mode."

5. DO NOT repeat the notification after 5 minutes.

6. DO NOT repeatedly remind me while the phone remains in Sound mode.

7. Leave the phone in Sound mode until I manually change it or library-exit

If I manually change:

VIBRATION → SOUND

again while still at the library:

This is a NEW manual override event.

StudyNest may show ONE new notification for that new event.

When I disconnect from all authorised library Wi-Fi:
→ Reset the manual-override notification state.
→ Follow normal library-exit behaviour.
→ Ensure NORMAL SOUND MODE is active.

IMPORTANT:

StudyNest must distinguish between:

override system.
